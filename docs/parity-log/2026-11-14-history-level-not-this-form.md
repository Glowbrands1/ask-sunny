# An earlier warning is history, not this form's level (HISTORY_LEVEL_NOT_THIS_FORM_ENABLED)

**Change.** QA, 14 Nov 2026: "verbal warning on 9/21. late again for 30 mins today" and "written warning for the same
thing, now late today" were read as this form's level. With the flag on (default off), a named level followed by its
own date on another day, or by "for the same thing / that / it", is a step on file unless a request verb in the same
sentence asks for it.

**Ask Bubbles: already there.** Its warning-level reader has classified both shapes as history since 9 Oct 2026
(`classify`: a level dated on another day, or "for the same thing", is historical). This ports the mechanism into Ask
Sunny's own reader. Bubbles' owner rule that "given verbal warning on 9/21" records Verbal is not part of this port.
