# Parity log — one file per entry

Each entry saying why a fix stays in one app, or how it was ported, is its own
file here: `docs/parity-log/YYYY-MM-DD-<short-slug>.md`. Pull requests that
each add an entry then never touch the same file, so they never conflict
(QA, 3 Nov 2026: every pull request that appended to one shared log
conflicted with the next one merged).

Entries up to 3 Nov 2026 are in `docs/parity-log.md`, unchanged.
