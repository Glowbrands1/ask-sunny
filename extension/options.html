ASK Sunny Review Sync

Setup — one URL and one token.

This extension never handles Google sign-in

It reads only the review content Google has already rendered on your Reviews page while you are signed in normally. It does not ask for, store, or transmit your Google email, password, cookies, session or multi-factor codes, and it contains no code that could. If Google signs you out, sign back in as you normally would and return to the Reviews page.
